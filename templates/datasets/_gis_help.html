Q QGIS
    {% if kind == "gdb" %}
  1. Menu Layer → Add Layer → Add Vector Layer.
  2. Set Source type to Directory, and Type to OpenFileGDB.
  3. Browse to the unzipped .gdb folder → Add, then choose the layers.
    4. {% elif kind == "package_pro" or kind == "package_arcmap" %}
  4. ArcGIS packages are designed for ArcGIS. In QGIS, rename the file to .zip, unzip it, and add the shapefiles or .gdb inside.
    5. {% elif kind == "qgis" %}
  5. Double-click the {{ ds.file_format }} file, or Project → Open.
    6. {% elif kind == "raster" or kind == "grid" %}
  6. Menu Layer → Add Layer → Add Raster Layer{% if direct_url %} (or choose Protocol: HTTP(S) and paste the direct link above){% endif %}.
  7. Select the file → Add. Use Raster → Analysis and the Processing Toolbox for slope, hillshade, zonal statistics, etc.
    8. {% elif kind == "table" %}
  8. Menu Layer → Add Layer → Add Delimited Text Layer (CSV) or drag the Excel file into QGIS.
  9. Choose the longitude (X) and latitude (Y) columns to display points.
    10. {% else %}
  10. Drag the downloaded file{% if kind == "shapefile" or kind == "zip" %} (the .zip works directly){% endif %} into the QGIS map window, or use Layer → Add Layer → Add Vector Layer.
    11. {% if direct_url %}
  11. Or load it straight from the portal: Add Vector Layer → Source type: Protocol: HTTP(S), paste the direct link above.
    12. {% endif %}
  12. Analyse with the Processing Toolbox (Ctrl+Alt+T): buffer, clip, intersect, count points in polygon, etc.
    13. {% endif %}
Pro ArcGIS Pro
    {% if kind == "package_pro" or kind == "package_arcmap" %}
  1. Double-click the downloaded {{ ds.file_format }} file. ArcGIS Pro opens it and adds the layers with their symbology.
    2. {% elif kind == "geojson" %}
  2. Open the Geoprocessing pane → search JSON To Features.
  3. Input: the downloaded .geojson. Output: a feature class in your project geodatabase → Run.
    4. {% elif kind == "kml" %}
  4. Geoprocessing → KML To Layer → choose the file → Run.
    5. {% elif kind == "table" %}
  5. Add the table to the map (Map tab → Add Data), then right-click it → Display XY Data.
    6. {% elif kind == "qgis" %}
  6. QGIS projects can't be opened in ArcGIS Pro. Download the data layers listed in the description instead.
    7. {% else %}
  7. In the Catalog pane, right-click Folders → Add Folder Connection → choose the folder where you unzipped the data.
  8. Expand the folder{% if kind == "gdb" %} and the .gdb{% endif %}, then drag the layer onto the map.
    9. {% endif %}
  9. Analyse with the Analysis tab → Tools (Buffer, Clip, Summarize Within, Spatial Analyst tools for rasters).
Map ArcMap & ArcCatalog (ArcGIS Desktop 10.x)
    {% if kind == "package_arcmap" %}
  1. Double-click the .mpk / .lpk file to open it in ArcMap.
    2. {% elif kind == "package_pro" %}
  2. ArcGIS Pro packages (.mpkx, .ppkx, .lpkx) don't open in ArcMap. Use ArcGIS Pro or QGIS.
    3. {% elif kind == "geojson" or kind == "geopackage" %}
  3. ArcMap doesn't read {{ ds.file_format }} directly. Open it in QGIS or ArcGIS Pro and export to a shapefile or File Geodatabase.
    4. {% elif kind == "kml" %}
  4. ArcToolbox → Conversion Tools → From KML → KML To Layer.
    5. {% elif kind == "qgis" %}
  5. QGIS projects can't be opened in ArcMap.
    6. {% else %}
  6. In ArcCatalog: click Connect to Folder and choose the unzipped folder. You can preview the data and its metadata there.
  7. In ArcMap: drag the layer from ArcCatalog (or the Catalog window) onto the map, or use File → Add Data.
    8. {% endif %}
  8. Analyse with ArcToolbox (Analysis Tools, Spatial Analyst, Conversion Tools).
